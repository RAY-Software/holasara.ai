# holasara.ai — sitio de Sara

Sitio de marketing de **Sara**, la recepción con IA para clínicas: atiende WhatsApp e Instagram
24/7, agenda, cobra anticipos, baja ausencias y reactiva pacientes.

- **Stack:** Astro 5 + Tailwind 4 (estático)
- **Dominio:** https://holasara.ai
- **Idioma:** Español (LATAM). EN se puede sumar bajo `/en`.
- **Marca:** paleta Salvia (verde pino `#1F7A5C` · menta `#2FB985` · crema `#F3F0E7`), tinta bosque `#14261F`.
  Tipografía: Fraunces (display) + Inter (cuerpo).

## Desarrollo

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # dist/
```

Contenido y copy salen del sales deck "RAY Health v2". El producto es RAY (clinic-platform);
este sitio es la marca de cara al cliente, independiente de la marca madre.
