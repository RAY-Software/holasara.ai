# Logo de Sara

Símbolo **monograma** (dirección A): la "S" en Chopin Black dentro de un cuadrado tinta,
con el punto menta "en línea". El punto es el gesto de marca: la recepción que no se apaga.

Todos los SVG tienen la "S" convertida a **path vectorial** (no dependen del font Chopin),
así se pueden usar en cualquier editor (video, Figma, etc.).

## Archivos

| Archivo | Uso |
|---|---|
| `sara-mark.svg` | Símbolo principal (cuadrado tinta) |
| `sara-mark-cream.svg` | Símbolo para fondos oscuros (cuadrado crema) |
| `sara-mark-pine.svg` | Variante con cuadrado verde pino |
| `sara-mark-glyph-tinta.svg` | Solo "S" + punto, fondo transparente (S tinta) |
| `sara-mark-glyph-cream.svg` | Solo "S" + punto, transparente (S crema, para video sobre oscuro) |
| `sara-wordmark.svg` | Wordmark "Sara" + punto (tinta) |
| `sara-wordmark-cream.svg` | Wordmark para fondos oscuros |
| `sara-mark-{1024,512,256,180,64,32}.png` | Símbolo en PNG (transparente) |
| `apple-touch-icon.png` | Ícono iOS (180px, fondo tinta) |

Para el **video**: usá `sara-mark-glyph-cream-1024.png` o `sara-mark-cream.svg` sobre fondos oscuros,
y `sara-mark.svg` sobre claros.

## Colores

- Pino `#1F7A5C` · Menta `#2FB985` · Tinta bosque `#14261F` · Crema `#F3F0E7`

Tipografía de marca: **Chopin Trial** (display) + Inter (cuerpo).
